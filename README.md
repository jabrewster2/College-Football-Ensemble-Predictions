# College-Football-Ensemble-Predictions
Using open source data and sklearn I am making a voting ensemble to predict College Football games.

To get started and running this code yourself I recommend uploading this file to Google Colab so you can use the GPUs they provide if you don't have a powerful PC. 

You are going to have to upload the data set found here https://www.kaggle.com/datasets/cviaxmiwnptr/college-football-team-stats-2002-to-january-2024 into the file manager of Colab then copy and paste the path into the path_to_file variable in the first cell.
